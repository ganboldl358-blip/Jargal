# Петрографийн мэдээллийн санг 3D геологийн загварчлал, судалгаа, тайлалд ашиглахад шаардагдах өгөгдөл

**Төсөл:** Oval Ni-Cu (Asian Battery Metals / AZ9)
**Зориулалт:** Петрографийн дээжийн нэгдсэн мэдээллийн санг (1) 3D геологийн загварчлал, (2) судалгаа-шинжилгээ, (3) геологийн тайлалд ашиглах.

---

## 1. Яагаад энэ бүтэц хэрэгтэй вэ

Петрографийн тайлбар (шлиф, аншлиф) нь өөрөө текстэн мэдээлэл тул 3D орчинд шууд ашиглагдахгүй. Ашиглагдахын тулд дээж бүр:

1. **Орон зайн байрлалтай** байх ёстой — цооногийн дээж бол Цооногийн дугаар + гүн, гадаргын дээж бол X, Y, Z солбицол.
2. **Кодлогдсон (ангилсан)** байх ёстой — чөлөөт текстийг стандарт кодын хүснэгтээр (lookup table) чулуулгийн нэр, хувирал, хүдэржилтийн код болгож хөрвүүлнэ. Leapfrog/Micromine/Datamine зэрэг программ зөвхөн кодлогдсон багана дээр интервал загварчилдаг.
3. **Нэгдсэн түлхүүртэй** байх ёстой — SampleID нэг стандартаар, HoleID нь Collar хүснэгттэй яг таарч байх (MU-23-01 ≠ MU2301 гэх мэт зөрүүг арилгах).

## 2. Шаардагдах хүснэгтүүд (3D загварчлалын стандарт багц)

### 2.1 Заавал байх — үүнгүйгээр 3D боломжгүй

| Хүснэгт | Талбарууд | Тайлбар |
|---|---|---|
| **Collar** | HoleID, East, North, RL(Z), EOH_Depth, Azimuth, Dip, Grid/CRS, Drill_Type, Date | Цооногийн амны байрлал. CRS-ээ нэг мөр болгох (UTM zone, datum — баталгаажуулах) |
| **Survey** | HoleID, Depth, Azimuth, Dip | Цооногийн гүний чиглэлийн хэмжилт (downhole survey). Байхгүй бол collar-ын аз/налуугаар шулуун гэж үзнэ — гүн цооногт алдаа өгнө |
| **Petrography (дээж)** | SampleID, HoleID, Depth_From, Depth_To (эсвэл Depth_m цэг), эсвэл гадаргын дээжид East/North/RL | Дээж бүрийг орон зайд байрлуулах түлхүүр |

### 2.2 Петрографийн атрибутууд (дээж бүрд)

| Бүлэг | Талбарууд |
|---|---|
| Таних | SampleID, Lab_ID, Sample_Type (шлиф/аншлиф/гар дээж), Lab, Analyst, Report_Date, Source_File |
| Чулуулаг | Rock_Name (стандарт, англи), Rock_Name_Original (монгол эх), Rock_Code (богино код, ж: GB=габбро, OL-WEB=оливин вебстерит), Protolith |
| Бүтэц, текстур | Texture, Grain_Size, Structure |
| Эрдсийн бүрэлдэхүүн | Mineral_1..n + Pct_1..n (модаль %), эсвэл "эрдэс:%" урт формат. Гол эрдсүүдийг тусдаа баганад (Ol_pct, Px_pct, Pl_pct, Amph_pct, Serp_pct…) гаргавал статистик/интерполяцид шууд ашиглагдана |
| Хувирал | Alteration_Type (серпентинжилт, уралитжилт, хлоритжилт…), Alteration_Intensity (weak/mod/strong эсвэл 1–5) |
| Хүдэржилт | Opaque_Minerals (пирротин, пентландит, халькопирит, магнетит…), Sulphide_Pct, Ore_Texture (disseminated/net-textured/massive) |
| Баримтжуулалт | Photo_PPL, Photo_XPL, Photo_HandSpecimen (файлын зам/линк), Description (эх тайлбар) |

### 2.3 Хамт байвал тайлалд хүчтэй болдог (санал болгож буй нэмэлт)

| Өгөгдөл | Юунд хэрэгтэй |
|---|---|
| **Lithology log** (интервалын геологийн бичиглэл) | Петрографийн цэгэн дээжийг интервалын геологитой шүүрдэж, 3D литологийн solid загварын гол орц болно |
| **Assay** (Ni, Cu, Co, S, PGE, MgO…) | Петрографи ↔ агуулгын хамаарал: аль чулуулаг/текстурт хүдэржилт байгааг тоогоор батлах |
| **Alteration log** | Хувирлын 3D бүрхүүл (shell) загварчлах |
| **Structural data** (цооногийн бүтцийн хэмжилт, alpha/beta) | Хүдрийн биетийн байрлал, чиглэлийн тайлал |
| **Геофизик** (соронзон, IP/resistivity 3D инверс) | Петрофизик ↔ петрографи холбоо: серпентинжилт-соронзон, сульфид-chargeability |
| **Whole-rock geochemistry / XRD / SEM** | Чулуулгийн ангиллыг тоон аргаар баталгаажуулах |
| **Density / magnetic susceptibility хэмжилт** | Дээж бүрийн петрофизик — геофизикийн инверсийн хязгаарлалт |

## 3. Кодын хүснэгтүүд (lookup tables)

Нэгдсэн санд дараах жагсаалтууд тусдаа хүснэгтээр байна:

- `lu_rock_type` — Rock_Code, Rock_Name_EN, Rock_Name_MN, Rock_Group (ultramafic/mafic/sedimentary/…)
- `lu_mineral` — Mineral_Code (Ol, Cpx, Opx, Pl, Srp, Chl, Po, Pn, Ccp…), нэр (EN/MN)
- `lu_alteration` — код, нэр, эрчмийн скала
- `lu_lab` — лаборатори, шинжээч

## 4. Файлын формат

- **Мастер сан:** нэг Excel workbook (хүснэгт тус бүр sheet) + CSV хувилбарууд (UTF-8) + SQLite (.db) — GIS/Python-д шууд уншигдана.
- **3D программд оруулах:** Collar.csv, Survey.csv, Petrography_intervals.csv — Leapfrog/Micromine-ий интервал импортын форматтай нийцсэн.
- **Зураг:** дээжийн фотог файл нэрээр нь SampleID-тай холбож, санд зөвхөн зам/линк хадгална.
