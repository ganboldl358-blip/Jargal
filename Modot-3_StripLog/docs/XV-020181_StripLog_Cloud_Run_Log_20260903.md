## 5. QC-д илэрсэн, ЗАСАГДСАН 3 алдаа

1. **Мөнхийн давталт** — тайлбарын шошгын давхцлыг арилгах `while` нь хөвөгч таслалын
   алдаанаас (`(x+0.69)-x < 0.69`) хэзээ ч зогсохгүй болж, нэг цооног дээр процесс 100% CPU-тэй
   өлгөгдөж байв. `max()`-аар сольсон.
2. **Удаан зурах** — matplotlib-ийн `wrap=True` нь зурах болгонд мөрийг дахин тааруулдаг
   (O(n²)). `textwrap`-аар урьдчилан таслах болов: **4 мин 38 сек → 7 сек / цооног**.
3. **«Хувирал · бүтэц» багана хоосон гарч байсан** — Log_Detail-ийн хувирлын эрчим Excel-д
   ТЕКСТЭЭР (`'1'`,`'2'`,`'3'`) хадгалагдсан бөгөөд `num()` мөрийг тоо болгож задалдаггүй байсан
   тул **197 утга чимээгүй хаягдаж** байв. Одоо цахиуржилт, серицитжилт, хлоритжилт,
   эпидотжилт, карбонатжилт зэрэг бүгд зурагдаж байна. Зурвасын өргөнийг мөн 55–100% болгож
   уншигдахуйц болгов.

Мөн тайлбарын текст фотоны багана руу халиад байсныг DejaVu Sans-ийн кирилл тэмдэгтийн
бодит өргөнөөр (TextPath-аар хэмжсэн 0.55–0.58 em) дахин тохируулж засав.
