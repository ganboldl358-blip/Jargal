# ORD — цооногийн мэдээллийн платформ

**ORD** (Орд) нь өрөмдлөгийн логлолт, дээжлэлт, QA/QC, интерсепт, баганан лог, план зураг, огтлол, 3D-г нэг дор хийдэг
веб апп. Майхан ууланд MX Deposit-оор ажиллахад тулгарсан асуудлууд дээр суурилж, түүнийг орлох зорилгоор бүтээв.

- Build алхамгүй: цэвэр ES module + Preact/htm (vendor/ дотор), серверт тавихад л ажиллана.
- **Интернетгүй** ажиллана (IndexedDB + service worker) — кернийн агуулахад tablet дээр.
- claude.ai artifact болгон нийтлэхэд **хамтын, шууд** (live) хадгалалт руу автоматаар шилжинэ — байгууллагын бүх
  геологич нэг өгөгдөл дээр зэрэг ажиллаж, засварууд мөр бүрээр нэгтгэгдэнэ.
- Монгол / English интерфейс.

## Ажиллуулах

```bash
# репогийн үндсээс (database/csv-г Oval dataset болгон ачаалахын тулд)
python3 -m http.server 8000
# → http://localhost:8000/app/
```

Анх нээхэд «Red Hill demo (synthetic)» туршилтын төсөл үүснэ. «Төслүүд» хуудаснаас:
- **Oval (Ямбат) мэдээллийн сан** — энэ репогийн `database/csv/` (76 цооног, 1,990 survey, кернийн петрографийн
  дээж, шинжилгээ) нэг товчоор ачаална;
- шинэ төсөл үүсгэж, CSV / Excel / MX Deposit export-оос импортлоно.

Тест: `node --test app/tests/*.test.js`

## MX Deposit-оос юугаараа илүү вэ

| Асуудал (MX Deposit) | ORD |
|---|---|
| Импорт «Succeeded» гээд 0 мөр оруулж болно (assign/lock) | Урьдчилсан шалгалт (dry run): шинэ / өөрчлөгдөх / татгалзсан мөр бүрийг шалтгаантай нь харуулсны дараа л бичнэ |
| ID-update CSV-ийн хоосон нүд утгыг арилгана | Хоосон нүд одоогийн утгыг хадгална (арилгах нь тусдаа сонголт) |
| Импортоор мөр устгах боломжгүй, давхардал нэмэгдэнэ | Устгах, хуваах, нэгтгэх; засвар бүр, импорт бүрийг бүтнээр нь буцаана (undo); мөр бүрийн түүх |
| Жагсаалтад байхгүй код job-ыг унагаана | Импортын өмнө харуулж, нэг товчоор жагсаалтад нэмнэ; MT, AHGO зэрэг «бүү ашигла» кодыг тэмдэглэнэ |
| Завсар хүлээж авахгүй, «Not measured» мөрийг гараар | Мөр дээр шууд харагдана, нэг товчоор бөглөнө; MX export автоматаар нэмнэ |
| Хуучин веб гридэд мөр нэмэх/засах боломжгүй | Excel шиг грид: блок paste, Ctrl+D, кодын dropdown (утга, өнгөтэй), гараар бүрэн удирдах |
| Session ~1 цагт дуусна | Session байхгүй; офлайн ажиллана |
| — | 36 шалгалтын дүрэм шууд: EOH, dogleg, lon/lat солигдол, 500 тэмдэгт, QC оруулалт, **CMSQ-ийн MU v4 химийн дүрэм** (4-acid Al<1 %, S<5 %), MSUL/VMS ба логдсон сульфид % |
| QC график хязгаартай | CRM Shewhart график, blank, давхар дээжийн HARD, багцыг accept/review/reject |
| 3D, огтлолд Leapfrog хэрэгтэй | Баганан лог, план зураг, огтлол, 3D суурилуулсан; Leapfrog-т бэлэн export |
| Кернийн зураг тусдаа хавтсанд | `MU2611_0.00-7.70_Box 1-2.JPG` нэршлээс цооног/гүн/хайрцаг/Wet-Dry-г уншиж интервалд холбоно; сонгосон интервалын зураг грид доор гарна |
| — | «Асуух» (claude.ai дотор): Claude төслийн өгөгдлийг зөвхөн уншиж, асуултад цооног, гүнтэй нь хариулна |

MX Deposit давуу хэвээр: байгууллагын түвшний эрхийн удирдлага, Leapfrog Central/Evo-той шууд холболт, олон жил
хэрэглэгдсэн tablet апп, лабораторийн шууд холболт. Шилжилтийн үед ORD нь MX-д бэлэн CSV гаргаж зэрэг ажиллуулж болно.

## Кодын стандарт

`src/core/codes.js`:
- **LITH = MU Lithology Code Standard v4** (2026-09-23): MX Lith1-ийн 34 код + `FRHYF` `SCHRF`. `FRHYF/SCHRF` ба Texture
  `VUG` нь MX list-д нэмэгдээгүй тул MX export `FRHY/SCHR`-ээр орлуулж, тайланд бичнэ.
- **ALT = MX A-кодууд** (AltCode v1 MX-д хэрэглэгдэхгүй тул ачаалаагүй).
- Цөөн кодын утгыг (`?` тэмдэгтэй) албан ёсны `MU_Lithology_Codes_v4.xlsx`-ээр батлах шаардлагатай —
  «Кодын жагсаалт» хуудаснаас CSV импортлоход кодоор нь утга, өнгө шинэчлэгдэнэ.

## Бүтэц

```
app/
  index.html        бие даасан хувилбар (PWA, офлайн)
  artifact.html     claude.ai artifact-ийн эхлэл (хамтын хадгалалт)
  styles.css        design tokens (цайвар / бараан)
  vendor/           preact+htm, three.js, OrbitControls, SheetJS (MIT/Apache)
  src/core/         өгөгдлийн цөм — store (түүх, undo, мөрийн нэгтгэл), schema, validate, desurvey (minimum
                    curvature), structure (alpha/beta → dip/dip dir), intervals, importer, lab, export, qaqc,
                    sampling, intercepts, cloud, persist, demo, oval
  src/ui/           shell, грид, хуудсууд (views/)
  tests/            node --test
```

Өгөгдлийн загвар: (цооног × хүснэгт) тутамд нэг «баримт», мөр бүр `id`, `_t` (цаг), `_u` (хэрэглэгч)-тэй. Устгал нь
tombstone тул синк, undo, түүх бүгд мөрийн түвшинд ажиллана.
