# Oval Project — Petrography Database

Oval Ni-Cu төслийн (Asian Battery Metals / AZ9) петрографийн дээжүүдийн нэгдсэн мэдээллийн сан.

- `docs/` — 3D геологийн загварчлал, судалгаа, тайлалд шаардагдах өгөгдлийн баримтжуулалт
- `workspace/` — Google Drive-аас татаж задалсан завсрын өгөгдөл (инвентор, CSV)
- `database/` — нэгдсэн мастер мэдээллийн сан (CSV / XLSX / SQLite)
- `scripts/` — сан бүтээх скриптүүд

Эх сурвалж: Google Drive дээрх Oval төслийн петрографийн тайлан, хүснэгтүүд (шлиф, аншлиф, Khanlab, MIRESL зэрэг).
